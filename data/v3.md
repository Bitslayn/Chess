# Chess compression v3
Yes, this takes some inspiration from https://codegolf.stackexchange.com/a/19416

## Header
I will start with a header rather than end with one this time around as the header will be used to tell the parser how to read the board.
### Turn Side - 1 bit
Flag that shows whose turn it is. *This is unchanged.*
```
0b0 - White
0b1 - Black
```

### Castling - 1 or 5 bits
Variable width whether any rook can castle. The optimization only optimizes mid-game.
```
0b0 - Not castling
0b1xxxx - Castling
```

### En Passant
Knowing whose turn it is, there can only be 4 potential pawns in the rank that can do en passant. If there is an en passant, the nth pawn can do en passant.
```
0b0 - None
0b1xx - En passant (0-3)
```

### Halfmove Clock - 4 or 7 bits
Keeps track of the fifty-move rule using a variable width number. The first bit says whether the number exceeds 7, and can count up to 63 with 50 being the absolute limit.
```
0b0xxx - Short (0-7)
0b1xxxxxx - Long (0-63)
```

### Fullmove Clock - 8 bits
Keeps track of the number of full moves using an 8-bit number or 1-256. Even though there is no limit to the number of moves, this number is limited as it is improbable to have this many moves happen in a game. *This is unchanged.*
```
0bxxxxxxxx
```

### Huffman Material - 10 bits
Says which of PBNRQ for white then black are in play.
```
0bxxxxx bxxxxx
```
## Board

### Operators - 1 bit
The operator tells the parser what to do with the next several bytes. It is impossible to start with a repeat operator. Pairing an operator with its defining bits forms a single instruction.

The chess board is indexed 0 - 63
```
0b0 - Piece
0b1 - Empty
```

#### Piece - Huffman tree
Depending on the Huffman material bits, the Huffman tree used for the pieces of each color could be different.
```
0b0 - Empty
0b10... - White
0b11... - Black
```
This is an example of the Huffman tree at the start.
```
0b1x0 - Pawn
0b1x100 - Bishop
0b1x101 - Knight
0b1x110 - Rook
0b1x1110 - Queen
0b1x1111 - King
```

#### Empty - 4 or 7 bits
For redundancy, and to optimize large regions of empty space. Only used when there are more than 3 empty spaces in a line. This is also a variable width number. The first bit says whether the number exceeds 8, and can count up to 64.
```
0b0xxx - Short (1-8)
0b1xxxxxx - Long (1-64)
```
